# Threads Studio 작업 기록

2026-09-27. 이전 대화 ‘기획안 최종 검토’의 초기 프로젝트를 현재 폴더로 복사했다. 원문 요구사항은 original-requirements.txt에 보존한다.

## 확정 사항
- Gemini API 우선, 명시적으로 설정한 GPT API를 장애 시 대체 사용.
- 외부에서 작성한 글 일괄 등록 지원. 무료 한도 소진 시 기존 예약은 유지.
- 한국어 관리자, 계정별 하루 3회(08:00, 12:30, 21:30 / Asia/Seoul), 기본 검토 모드.
- 본문/답글 단계별 영속 기록, 불확실한 결과 재전송 금지, 승인본 스냅샷, 긴급 중지.
- 제휴 본문 첫 광고 표시 필수. 정확한 등록 링크·고지 문구를 서버가 삽입.
- 최초 로컬 Windows 운영. 외부 공개 배포와 실제 게시 시험은 아직 수행하지 않는다.

## 구현 순서
1. 인증·저장소·계정/상품/주제 CRUD.
2. 생성·검증·예약·모의 및 실제 게시 어댑터.
3. 한국어 운영 화면.
4. 장애 테스트·빌드·설치 및 복구 문서.

## 구현됨

- 한국어 관리자 인증·대시보드·계정·주제·상품·콘텐츠·예약 목록·기록·설정 화면.
- Gemini 우선 / 선택 설정된 GPT 대체 HTTP 어댑터, 모델 목록 조회·구조화 응답 연결 시험.
- 정확한 상품 고지·링크 삽입, 계정 분리, 승인 스냅샷, 상품 만료/철회 검사.
- 영속 슬롯 UNIQUE, 원자적 슬롯/콘텐츠 등록, 작업 잠금, 단계별 발행 기록.
- 공식 OAuth 및 토큰 수동 갱신, 텍스트·단일 이미지·단일 영상 컨테이너 어댑터.
- 최대 3개 답글, 부분 실패 복구, 응답 유실 재전송 차단, 긴급 중지.
- 다음 날 자동 편성, 여러 날 비율, 상품 14일 간격, 일상 대체, 지연 건너뛰기.
- 외부 글 일괄 등록, 3일치 생성 요청, 호출 횟수/예약 예산 제한.
- 백업·빈 저장소 복원 스크립트, 복원 시 중지·미확정 작업 격리.

## 검증

- Node 24.19.0, npm ci 완료.
- TypeScript 검사 및 Vite 프로덕션 빌드 통과.
- 모의 테스트 10개 통과: 동시 작업/중복, 부분 실패, 응답 유실, 작업자 중단, 중지/변조, 지연, 슬롯/예산, 날짜/비율, 광고/근거/혼선, 100개 계정 300슬롯.
- 실제 HTTP 통합 테스트 통과 (총 11개 테스트 통과): 관리자 인증, 동일 출처 보호, 계정/20주제, 일괄 등록, 중복 슬롯, 승인.
- 로컬 4310 서버 실행 및 초기 화면 렌더링 확인. 사용자 관리자 비밀번호는 설정하지 않음.
- 실제 AI·Threads 계정·외부 게시·PostgreSQL 서버·백업 실제 복원은 미검증.

## 남은 기능 / 원문 대비 제한

아래는 외부 키가 없어도 구현을 더 진행할 수 있는 미완료 항목이며 완료로 표시하지 않는다.

- 선택 RSS/API 글감 수집, 출처 최신성 재조회, 가중 무작위 선택과 관점 변화 검증.
- 의미 유사도 및 주장별 근거 대조, 최대 2회 자동 재생성, 운영자 글 수정에서 규칙 개선 제안·버전 비교/복원.
- 캐러셀·파일 업로드·미디어 규격 검사/변환/저장소/메타데이터 제거.
- 예약 시간 변경의 기존 슬롯 적용 UI, 생성 실패 슬롯 다시 생성 UX.
- 실제 게시 ID·계정·시각·부모를 대조하는 불확실 결과 해소와 수동 게시물 연결.
- 자동 토큰 갱신, 공급자 공통 장애 회로 차단, 외부 알림 수신처.
- 실제 비용 정산과 보장 가능한 지출 상한(현재 호출당 예약 예산), 공식 성과 수집·제휴 실적 연결.
- 다중 PostgreSQL 작업자, 계정 수별 처리량, 잠금 만료·부모 삭제·미디어 오류·백업 복원 등 확장 시험.

계정 키·권한이 있어야 확인 가능한 항목: 실제 OAuth 및 앱 심사, 선택 모델 접근/무료 한도, Threads 본문/답글·미디어 게시, 제휴사별 정책. 완전 무인 운영이 실검증된 제품으로 간주하지 않는다.

## 2026-09-27 사용자 요청: GPT 구독 사용
GPT 대체 생성은 공식 Codex CLI + ChatGPT 로그인으로 교체했다. OpenAI API 생성 호출을 제거하고 API 키 환경변수를 CLI에 전달하지 않는다. CLI 로그인 방식 확인과 forced_login_method=chatgpt로 API 키 로그인은 거부한다. 기존 API 과금 UI 제거. 로컬 개인용 프로세스에만 사용하며 공개 서비스로 노출하지 않는다.


구독 실연결 시험: 공식 CLI를 통해 한국어 글 1편과 구조화 JSON 생성 성공. Threads 실제 게시 없음. 기존 회귀 11개와 비밀값 전달 차단 1개 테스트 통과.
