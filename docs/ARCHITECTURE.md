# 구조와 결정

- React 19 + Vite 7: 한국어 로컬 관리자 화면.
- Express 5: 세션 인증, 동일 출처 쓰기 요청 확인, 로그인 시도 제한, 요청 스키마 검사.
- Node 24 + TypeScript: 엔진과 공급자 어댑터. 외부 SDK 대신 명시적 HTTP 어댑터로 버전 결합 축소.
- PGlite: 로컬 PostgreSQL. DATABASE_URL이 있으면 pg 풀을 통한 PostgreSQL 사용. schema는 server/store.ts의 idempotent 초기화 SQL.
- records: 계정·상품·주제·콘텐츠·설정·사용량 JSONB. slots: 계정/현지 날짜/슬롯 UNIQUE. locks: 만료 잠금과 owner 확인. audit: 운영 이력.
- 예약 슬롯 확보와 글 저장은 단일 SQL CTE로 원자적으로 수행한다. 별도 메시지 브로커 없이 영속 레코드를 작업 큐로 조회한다.
- 발행 전 스냅샷 해시, 현재 계정/전체 중지/상품 근거 상태를 확인한다. 단계별 creating/ready/sending/complete/uncertain을 저장한다.
- 전송 중 프로세스가 죽은 경우에는 컨테이너/게시 성공 여부가 불명확하므로 재전송하지 않는다. 결과 대조가 불완전하면 보류가 우선이다.
- 암호화: AES-256-GCM, 관리자 비밀번호 scrypt. 운영 응답에 토큰·시크릿 미포함. 외부 에러 응답 본문을 로그에 기록하지 않음.
- 브라우저 인증 세션은 메모리 기반 12시간이다. 재시작하면 재로그인이 필요하지만 예약·콘텐츠는 유지된다.
- 외부 출처를 서버에서 임의로 다운로드하지 않는다. 등록 URL은 형식 검사만 하며 제휴 클릭을 만들지 않는다. 미디어는 Meta가 접근 가능한 URL을 전달하고 컨테이너 완료를 확인한다.

## 제한

로컬 PGlite는 단일 서버 프로세스용이다. PostgreSQL 다중 프로세스는 잠금 로직을 사용하지만 별도 상시 서버 통합 검증이 필요하다. 외부 API에서 엄격한 exactly-once를 제공한다고 주장하지 않는다.

문체/의미/사실 검증은 완전 자동 판정이 아니다. 현재 코드는 금지 표현·길이·명시적 위험 패턴·등록 근거·문자열 유사도를 검사한다. 사실을 의미적으로 전부 대조하는 검증기는 아직 없다. 자동 승인 전 계정별 콘텐츠를 확인해야 한다.
